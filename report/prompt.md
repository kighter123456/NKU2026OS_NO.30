# Lab1 提示词汇总

以下按实验操作环节整理提示词，供实操时使用，并非历史对话的逐字记录。以自己阅读源码、执行命令和记录现象为主，AI 辅助解释、排错和检查。

## 1. 环境准备

```text
我准备按照指导书从 Lab0 开始搭建环境，再完成 Lab1。请帮我梳理需要检查的工具和操作顺序，我会在终端逐项执行并核对结果。
```

## 2. 阅读启动代码

```text
我想先自己阅读内核入口代码。请给我一些阅读思路，帮助我理解设置栈指针、跳转到 C 函数以及启动初始化之间的关系。
```

## 3. 编译与运行

```text
我准备亲自编译代码并运行 QEMU。请说明应该观察哪些输出；如果结果与指导书不一致，我会提供日志，请帮我分析排查方向。
```

## 4. GDB 调试

```text
我想用 GDB 跟踪从启动到进入内核的过程。请指导我设置断点、单步执行和查看寄存器，我会记录观察结果，再结合源码理解每一步的作用。
```

## 5. 理解输出过程

```text
我准备沿着内核打印函数查看调用关系。请帮我理解格式化输出如何调用 SBI 服务，以及这个过程中 CPU 特权级如何变化，我会结合调试结果验证。
```

## 6. 整理实验报告

```text
我会整理自己的代码阅读笔记、操作记录和测试截图。请按实验模板帮我检查练习回答是否完整，并指出需要补充的 OS 原理知识点，结论要与实际观察一致。
```

## 7. 检查提交内容

```text
我准备将代码和报告提交到小组仓库的 lab1 分支。请帮我核对 code、report 和截图目录是否符合要求，指导书和编译产物不要上传。
```

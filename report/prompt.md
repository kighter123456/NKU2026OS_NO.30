# Lab1 提示词汇总

## 记录范围

本文件汇总本次 Lab1 实验会话中实际收到的用户请求，包括环境与实验实现、报告完善、仓库提交和交付结构调整。界面自动附带的环境状态、授权验证码及系统指令不作为用户提示词。首次实现与部署为 2026-10-07，报告及目录调整为 2026-10-09，交付格式整理为 2026-10-10。

本会话没有用户另行提交的逐函数四段式提示词，也没有记录独立的“修改提示词再生成代码”过程。启动问题由 AI 根据真实工具输出继续修复；下文不会把事后整理的技术说明冒充当时输入过的提示词。模板所要求的“最终提示词”对应 P01，报告中同时解释其实际实现过程。若小组在本会话以外也使用过 AI，相关提示词不在此记录范围内。

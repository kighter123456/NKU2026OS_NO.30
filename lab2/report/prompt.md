# Lab2 提示词

## 共同约束

以本仓库 lab1/code 的副本为基础开发，所有仓库修改仅限 lab2，禁止修改 lab1。独立验证使用 Bare 模式，不实现页表或写 satp；补齐必需的公共接口、DTB 解析、启动参数传递和测试入口，并列出交给后续协作者的接口。署名注释为 lab2: 2414067，默认使用 Best-Fit，同时支持构建 First-Fit 和 Buddy。

## P1：DTB、页面布局与初始化

实现 DTB 解析和 page_init，将 a0 中的 hartid 与 a1 中的 DTB 物理地址传入 kern_init，在 BSS 清零后解析内存信息。校验 FDT 魔数、大小、块边界、字符串和结构 token，按节点的 address-cells/size-cells 解码 RAM，支持 QEMU 单段 DRAM，遇到额外不连续 bank 时明确报错；无效信息触发 panic，不使用硬编码容量兜底。管理范围取实际 RAM 与 [0x80000000,0x88000000) 的交集，打印探测范围和管理范围；npage 表示物理页号上界，pages 覆盖 [nbase,npage)，描述符数组放在内核 end 之后，并从空闲区排除固件、内核、描述符及不足一页的区间，空区间不调用 init_memmap。复用已有打印、字符串和对齐设施，补齐必要的断言、链表、Page 和 pmm_manager；Bare 模式虚实偏移为零，地址转换集中在 PMM 接口中。说明虚拟地址、物理地址、物理页号与描述符之间的关系，检查加法溢出、页对齐、描述符空间不足、无可用页和地址转换边界，不设置 satp 或调用页表映射函数。

## P2：First-Fit 分析与基线

实现 First-Fit 物理页分配器，完成 default_init、default_init_memmap、default_alloc_pages 和 default_free_pages 对应的初始化、空闲区登记、分配和释放功能。空闲块按地址排序，只有块头记录 property 并挂入链表；分配时选择第一个足够大的块，拆出请求页数并保留余块；释放时允许分批回收已分配页面，先验证全部页面再改变状态，随后合并物理连续的前后空闲块。分配失败不得改变链表和计数，计数单位始终为页；alloc_pages(0) 和非法释放触发断言，资源不足返回 NULL。解释初始化、拆分、回收及合并逻辑，分析线性扫描成本、外部碎片和可采用的数据结构改进。

## P3：Best-Fit 实现

按 pmm_manager 接口实现完整 Best-Fit 模块，公共接口与 First-Fit 一致，扫描空闲块选择满足请求的最小块，同尺寸选择低地址，并注册 best_fit_pmm_manager 作为默认管理器。可以复用 First-Fit 的链表维护机制，但拆分、合并和空闲页计数必须正确，选块策略必须能通过测试与 First-Fit 区分。构造低地址大空闲块和高地址小空闲块，使两者均能满足同一请求，验证 Best-Fit 选择后者；补充精确匹配、块拆分、碎片导致分配失败以及失败不改变状态的测试。当前缺少课程原测试，新增测试需注明为自建，后续取得课程测试时保留原内容接入，不修改测试迁就实现。

## P4：Buddy 实现

### 实现

实现符合公共 PMM 接口的 Buddy 分配器，按物理页号对齐分阶，将任意可用连续区间初始化为若干最大合法二次幂块，不假设可用区起点或页数是二次幂。请求 n 页时向上取整到 2^order，记录原始请求 n 和实际阶，空闲计数扣除实际块大小，并为 SLUB 提供查询实际分配跨度的接口。使用分阶链表完成逐级拆分和递归合并，合并仅限同阶、确实空闲且满足 XOR 关系的伙伴，不得越过可用范围；free_pages(base,n) 必须使用原始分配头和原始请求 n，拒绝内部页、错误长度和重复释放，保持公共接口的请求语义不变。

### 测试

为 Buddy 分配器设计独立测试，覆盖非二次幂请求、各阶边界、逐级拆分、伙伴递归合并、非伙伴不合并、内存耗尽、完整回收及错误释放。使用独立占用位图检查分配区间不重叠，核对物理对齐、实际占用页数和空闲计数，检查释放后数量恢复及已分配数据保持正确；将错误长度、内部页和重复释放等预期失败场景放在独立 QEMU 启动中，只有命中对应检查才判为通过。

## P5：简化 SLUB 实现

### 实现

实现提供 kmalloc/kfree 的简化 SLUB 分配器，以公共 PMM 接口分配页面，再在页内管理 16、32、64、128、256、512、1024、2048 字节规格的对象，所有对象至少按 16 字节对齐，超过规格上限的请求走大对象连续页路径。每个 slab 页维护对象空闲信息，使用页面元数据和对象状态识别合法对象、未对齐或内部指针以及重复释放，检查页内容量、元数据对齐、大小计算溢出和内存耗尽；空页立即归还，kmalloc(0) 返回 NULL，kfree(NULL) 无操作。实现应能运行在 First-Fit、Best-Fit 和 Buddy 三种后端上，不依赖宿主 malloc，不引入 per-CPU 优化，并说明与 Linux 完整 SLUB 的功能差异。

### 测试

为简化 SLUB 设计独立测试，覆盖全部对象规格边界、跨多个 slab 页的分配、大对象、交错释放、释放后重新分配、数据隔离及页数恢复。检查返回地址的 16 字节对齐，写满每个请求的用户字节并验证其他存活对象内容不变，全部释放后核对空闲页数恢复；补充内存耗尽、零大小、大小溢出、内部指针和重复释放场景，非法释放在独立 QEMU 启动中验证，任何非预期失败都必须使测试 runner 返回失败状态。

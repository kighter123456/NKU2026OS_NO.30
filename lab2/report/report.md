## 3. 初始化与核心结构

DTB 解析检查 FDT 头、长度、结构/字符串块、保留表终止项、token、嵌套和属性边界，根据父节点 cells 解码 RAM。支持 1/2-cell 字段，拒绝零大小、溢出及不连续 bank。前提是 OpenSBI 提供可读 DTB 地址，不声称能安全探测未知物理地址。

地址关系：

```text
nbase = DRAM_BASE / 4096
npage = managed_end / 4096
Page 数量 = npage - nbase
page2pa(pages+i) = (nbase+i)*4096
KVA = PA + va_pa_offset
```

管理终点取实际 RAM 末端与 PHYSTOP 的较小值，再向下页对齐。Page 数组放在内核 end 后向上对齐处，自身占用也要排除；空闲起点是数组末端向上页对齐的地址。先把所有描述符置 reserved，再只登记完整空闲区；没有完整页时不调用 init_memmap。

当前 Page 为 56 字节。128 MiB 对应 32768 个描述符，npage=0x88000，而不是 32768。实际布局见 [Best-Fit 日志](../code/evidence/selftest/best_fit-128M-case0.log)，不硬编码某次编译后的内核大小。256 MiB 启动识别全部容量，但明确打印低 128 MiB 管理上限。

## 4. 各分配器与练习问题

### First-Fit

init 清空链表和计数；init_memmap 将 reserved 区间转为空闲块，只有块头记录 property。alloc 找第一个足够大的块，取出前 n 页并登记余块；free 先验证完整范围，再按地址插入，与前后连续块合并，允许分批释放已分配页。

改进空间：next-fit 游标可减少重复扫描；分桶或平衡树可加速查找，但增加元数据和维护复杂度。合并与策略调整能缓解外部碎片，不能保证消除。

### Best-Fit

复用地址有序的拆分/合并机制，遍历找最小足够块，同尺寸选低地址。注册 best_fit_pmm_manager 并作为默认管理器。测试隔离低地址 8 页和高地址 4 页，申请 3 页，验证 First/Best-Fit 选择不同。

改进空间：维护大小索引并同时保留地址关系，减少全表扫描；过小余块也可能加剧碎片，不能直接认定 Best-Fit 总比 First-Fit 好。进一步应测搜索次数、失败率和碎片分布，本次没有虚构性能数据。

### Buddy

按 PFN 对齐将任意可用区拆为最大合法二次幂块，各阶维护链表。申请向上取整、逐级拆分；伙伴 PFN 用 XOR 计算，只合并同阶且空闲的伙伴，不越过可用边界。

申请 5 页实际占 8 页，记录请求和实际跨度，计数扣 8；释放必须传原始头和原始 5，拒绝内部页、错误长度、重复释放。优点是拆合规则明确，代价是内部碎片。它与 fit 的部分释放契约不同，已记录交接。

### 简化 SLUB

第一层 PMM 提供页，第二层将页切成 16～2048 字节规格对象，每页有 128 字节对齐头、空闲链和占用位图。更大对象申请连续页。对象 16 字节对齐，空页立即归还，用所有权及 bitmap 检查非法/重复释放。

实现只体现 SLUB 分层思想，没有 Linux 的 per-CPU、NUMA、锁和复杂回收策略，不能声称与 Linux 完整实现等价。

### 未知硬件内存范围（思考）

应优先读取启动协议提供的 DTB、UEFI GetMemoryMap、传统 x86 E820 等内存映射，并扣除固件保留区；ACPI 可提供相关拓扑信息。直接对未知地址写读探测可能访问 MMIO、触发总线错误或破坏数据，不是通用可靠方案。本项目未实现跨硬件通用探测 Challenge。

课程 basic_check/best_fit_check 仍缺失。自建测试不能代替原测试，取得后须保持内容不变接入。当前测试也不是并发、多 bank、分页权限或内存安全的形式化证明。

## 7. 原理对应与未覆盖知识

| 原理 | 实验对应与差异 |
|---|---|
| 地址空间 | Bare 下虚实数值相同；分页后数据访问仍需正确 KVA 映射 |
| 物理页元数据 | Page 描述物理帧，自身占 RAM，不是物理页内容或 PTE |
| 碎片 | Fit 的外部碎片，Buddy 的内部碎片 |
| 分层分配 | SLUB 在页上管理对象，仍存在规格及元数据开销 |
| 页表/TLB | 是 A/C 的依赖和调试对象，本次没有配置或验证 |
| 内核不变量 | 所有权、计数、无重叠；非法调用断言，资源不足返回 NULL |

重要但未实现：进程地址空间、用户态权限、按需分页、缺页异常、页面置换/交换、COW、共享内存、多核同步、NUMA 和完整堆安全。
